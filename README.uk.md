# P2P Streaming — WebRTC Mesh Application

![App Version](https://img.shields.io/badge/version-1.0.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)
![Platform](https://img.shields.io/badge/platform-macOS%20%7C%20Windows%20%7C%20Linux-lightgrey.svg)
![WebRTC](https://img.shields.io/badge/tech-WebRTC-orange.svg)

**P2P Streaming** — це сучасний децентралізований застосунок для трансляції екрана та спілкування, побудований на архітектурі **WebRTC Mesh**. Застосунок не потребує виділених медіа-серверів (SFU/MCU) — весь відео та аудіо трафік передається безпосередньо (Peer-to-Peer) між учасниками кімнати, що гарантує максимальну конфіденційність, низьку затримку та відсутність лімітів на час сесій.



## ✨ Ключові можливості

- **Нативний десктопний застосунок:** Доступний не лише через браузер, а й як повноцінна нативна програма для macOS, Windows та Linux на базі Electron.
- **Безкомпромісна якість:** Примусова передача відео у форматі 1920x1080 (і вище) при 60 FPS для демонстрації екрана.

## 🚀 Як користуватися застосунком

У цього застосунку є дві форми: **Десктопна версія (установчі файли)** та **Веб-версія (у браузері)**. Незалежно від платформи, вони повністю сумісні між собою.

### 1. Десктопна версія (Установчі файли .exe / .dmg / .AppImage)

Для максимальної продуктивності, підтримки нативних сповіщень та незалежності від вкладок браузера, ми надаємо десктопні версії.

**Встановлення:**
1. Перейдіть до розділу **Releases** нашого репозиторію на GitHub.
2. Завантажте установчий файл для вашої ОС:
   - **Windows:** Завантажте та запустіть файл `.exe`.
   - **macOS:** Завантажте файл `.dmg`. Відкрийте його та перетягніть іконку `P2P Streaming` до теки `Applications`.
   - **Linux:** Завантажте файл `.AppImage`. Зробіть його виконуваним (`chmod +x app.AppImage`) та запустіть.

**Використання:**
- При запуску ви побачите головне лобі застосунку.
- Натисніть **"Створити кімнату"**, щоб отримати унікальний код (наприклад, `A8F3K9`).
- Передайте цей код колегам або друзям.
- Щоб приєднатися до чужої трансляції, введіть код і натисніть **"Приєднатися"**.
- Використовуйте нижню панель керування, щоб увімкнути мікрофон або розпочати демонстрацію екрана.

### 2. Веб-версія (Задеплоєний застосунок)

**Використання:**
1. Перейдіть за офіційним посиланням веб-застосунку.
2. Дозвольте браузеру доступ до камери та мікрофона.
3. Логіка роботи ідентична десктопу. Код кімнати можна скопіювати одним кліком.

## 🛠 Посібник для розробників

### Вимоги
- **Node.js:** Версія 24 або вище.
- **Менеджер пакетів:** `pnpm` (версія 11+).

### Встановлення проєкту

1. Клонуйте репозиторій:
   ```bash
   git clone <url-вашого-репозиторію>
   cd p2p-streaming
   ```
2. Встановіть залежності:
   ```bash
   pnpm install
   ```
3. Налаштуйте змінні оточення в `.env`:
   ```env
   NUXT_PUBLIC_METERED_API_KEY=ваш_секретний_ключ_тут
   ```

### Локальна розробка

- **Веб-сервер для розробки (з Hot Reloading):**
  ```bash
  pnpm run dev
  ```
- **Запуск Electron у режимі розробки:**
  ```bash
  pnpm run app:dev
  ```

### Збірка застосунку (Білд)

- **Генерація статики для Веб-деплою (Vercel, Netlify):**
  ```bash
  pnpm run generate
  ```
- **Збірка установчих файлів Electron (Desktop App):**
  ```bash
  pnpm run app:build
  ```

### Continuous Integration & Release (CI/CD)

- **Автоматичні перевірки (CI):** При кожному Push/PR запускається `vue-tsc` та тестові збірки.
- **Випуск нового релізу (Release Pipeline):**
  Однією командою ви можете випустити нову версію для всіх ОС.
  ```bash
  pnpm run release
  ```
  Це автоматично підвищить версію, створить Git Tag, і GitHub Actions збере `.exe`, `.dmg`, `.AppImage` з публікацією у Releases.
