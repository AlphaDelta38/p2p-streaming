# P2P Streaming — WebRTC Mesh Application

**P2P Streaming** — это современное децентрализованное приложение для трансляции экрана и общения, построенное на архитектуре **WebRTC Mesh**. Приложение не требует выделенных медиа-серверов (SFU/MCU) — весь видео и аудио трафик передается напрямую (Peer-to-Peer) между участниками комнаты, что гарантирует максимальную конфиденциальность, низкую задержку и отсутствие лимитов на время сессий.

---

## ✨ Ключевые возможности продукта

- **Нативное десктопное приложение:** Доступно не только через браузер, но и как полноценная нативная программа для macOS, Windows и Linux на базе Electron.
- **Бескомпромиссное качество:** Принудительная передача видео в формате 1920x1080 (и выше) при 60 FPS для демонстрации экрана.

---

## 🚀 Как пользоваться приложением

У этого приложения есть две формы: **Десктопная версия (установочные файлы)** и **Веб-версия (в браузере)**. Вне зависимости от платформы, они полностью совместимы между собой.

### 1. Десктопная версия (Установочные файлы .exe / .dmg / .AppImage)

Для максимальной производительности, поддержки нативных уведомлений и независимости от вкладок браузера, мы предоставляем десктопные версии.

**Установка:**
1. Перейдите в раздел **Releases** нашего репозитория на GitHub.
2. Скачайте установочный файл для вашей ОС:
   - **Windows:** Скачайте и запустите файл `.exe`.
   - **macOS:** Скачайте файл `.dmg`. Откройте его и перетащите иконку `P2P Streaming` в папку `Applications`.
   - **Linux:** Скачайте файл `.AppImage`. Сделайте его исполняемым (`chmod +x app.AppImage`) и запустите.

**Использование:**
- При запуске вы увидите главное лобби приложения.
- Нажмите **"Создать комнату"**, чтобы получить уникальный код (например, `A8F3K9`).
- Передайте этот код коллегам или друзьям.
- Чтобы подключиться к чужой трансляции, введите код и нажмите **"Присоединиться"**.
- Используйте нижнюю панель управления, чтобы включить микрофон или начать демонстрацию экрана.

### 2. Веб-версия (Задеплоенное приложение)

**Использование:**
1. Перейдите по официальной ссылке веб-приложения.
2. Разрешите браузеру доступ к камере и микрофону.
3. Логика работы идентична десктопу. Код комнаты можно скопировать одним кликом.

## 🛠 Руководство для разработчиков

### Требования
- **Node.js:** Версия 24 или выше.
- **Менеджер пакетов:** `pnpm` (версия 11+).

### Установка проекта

1. Клонируйте репозиторий:
   ```bash
   git clone <url-вашего-репозитория>
   cd p2p-streaming
   ```
2. Установите зависимости:
   ```bash
   pnpm install
   ```
3. Настройте переменные окружения в `.env`:
   ```env
   NUXT_PUBLIC_METERED_API_KEY=ваш_секретный_ключ_здесь
   ```

### Локальная разработка

- **Веб-сервер для разработки (с Hot Reloading):**
  ```bash
  pnpm run dev
  ```
- **Запуск Electron в режиме разработки:**
  ```bash
  pnpm run app:dev
  ```

### Сборка приложения (Билд)

- **Генерация статики для Веб-деплоя (Vercel, Netlify):**
  ```bash
  pnpm run generate
  ```
- **Сборка установщиков Electron (Desktop App):**
  ```bash
  pnpm run app:build
  ```

### Continuous Integration & Release (CI/CD)

- **Автоматические проверки (CI):** При каждом Push/PR запускается `vue-tsc` и тестовые сборки.
- **Выпуск нового релиза (Release Pipeline):**
  Одной командой вы можете выпустить новую версию для всех ОС.
  ```bash
  pnpm run release
  ```
  Это автоматически повысит версию, создаст Git Tag, и GitHub Actions соберет `.exe`, `.dmg`, `.AppImage` с публикацией в Releases.
